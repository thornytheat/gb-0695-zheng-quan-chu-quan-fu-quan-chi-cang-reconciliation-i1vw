# 数据定义

除权参考价=(前收盘-每股现金+配股价×配股比例)/(1+送转比例+配股比例)，按登记日判定权益，零碎股单列。

输入字段：record, kind, security, alias, event_date, record_date, ex_date, price, cash, bonus, rights, rights_price, shares, version, reported_cash。所有ID按字符串保留；空字符串、NULL、N/A、未知与“-”视为缺失，不能当作数值零。数值使用Decimal，输出为十进制字符串。重复业务键相同内容计重复，内容冲突隔离或按明确修订号裁决，不按文件顺序盲目覆盖。

每条证据有原始行号，隔离记录有原因码及原值。时间区间使用半开边界；日期定义在各模块规则内显式声明。输入表头可调序，不得缺列或重复；中文旧编码可上传。规则版本存入运行清单，重跑使用原始文件内容摘要与规则版本共同确定幂等键。复核使用revision乐观锁，陈旧提交返回409。

每行position是投资者在event_date结束时的登记快照；同一证券同一除权日可含多条公告（如送股与配股各有登记日），合并为一个除权事件，不将多个日终快照相加。同一record编号视为同一公告的修订，取最高版本，同版本内容冲突隔离；不同record编号视为事件的不同组件，前收盘必须一致，现金/送转/配股比例的非零声明须唯一，配股价须一致，否则整事件隔离。登记日当天有权益，次日新增持仓无权益。每个组件按自身登记日选取不晚于该日的最新快照：快照日落在登记日当天为已核，早于登记日为待核（登记记录未到）。送转与配股产生的新增股份向下取整，零碎股保留。现金按每项行动总额四舍五入到分，再按最大余额分配，记录ID作稳定顺序。无税费及真实交易所连接。

参考价按事件合并后的公告数值计算并如期发布，不等待登记数据；除权因子明细的“参考价采用/持仓采用/待核行动/状态”列分别标明两条线各自采用的公告。持仓重算只计入已核组件，待核组件的股份与认配金额单列（待核股份、待核认配_CNY），不进新股份与合计；事件存在待核权益时参考价状态为暂定，依据补齐后的新批次中价格状态与持仓一起更新为确认。现金对账按投资者汇总已核应付，与所选快照的渠道报送合计比较。批次整体写入，复算中断不产生半写状态，旧批次保留可通过run_id核对。
